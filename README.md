# New Portfolio 2 — Rizwan Khan

A completely redesigned, single-page portfolio landing page for Rizwan Khan.

### Highlights
- Clean editorial UI with modern typography
- Three.js interactive 3D particle sphere
- AOS scroll-reveal animation system
- Scroll parallax and responsive motion
- Project hover tilt interactions
- UI/UX, web design and visual design positioning
- Responsive mobile-first layout
- No secondary pages — focused landing experience

### Stack
HTML · CSS · JavaScript · Three.js · AOS

### Run
Open `index.html` directly or serve the folder with a static web server.
