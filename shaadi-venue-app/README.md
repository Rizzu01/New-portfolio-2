# ShaadiVenue Android App

React Native / Expo frontend-only presentation app based on the Figma ShaadiVenue mobile screens.

## Scope
- Exact Figma-inspired onboarding, location, home, explore/search, venue listing and venue details flow
- Mock/local data only
- No backend, database or payment gateway
- Designed for Android APK presentation

## Build
Use the included GitHub Actions workflow to build the Android debug APK.
